# Security Policy

## Supported Versions

The latest release and the `main` branch are supported with security updates.
Older releases and forks may not receive security fixes.

| Version / Branch | Supported |
| --------------- | --------- |
| Latest release  | ✅        |
| `main`          | ✅        |
| Older releases  | ❌        |
